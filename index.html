      🛠️ Cài trợ lý bếp (ChatGPT Project)

      1. ChatGPT → Projects → New project, đặt tên Bếp nhà mình.
      2. Bấm Copy hướng dẫn bên dưới, dán vào mục Instructions của Project.
      3. Bấm Tải data.js, rồi thêm file đó vào mục Files của Project.
      4. Mở chat mới trong Project, bấm nút giọng nói để nói chuyện. Muốn cập nhật app thì nói "xuất cho app".
